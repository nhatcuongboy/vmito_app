# Hướng dẫn cấu hình Google API Keys cho Vmito App

## Tổng quan

App cần **2 API keys riêng biệt** vì requirements về restrictions khác nhau:

1. **Maps SDK Key** - Cho hiển thị bản đồ (native SDK)
2. **Places API Key** - Cho autocomplete địa chỉ (HTTP API)

---

## Bước 1: Tạo Key cho Maps SDK (Hiển thị bản đồ)

### Trên Google Cloud Console:

1. Vào **APIs & Services > Credentials**
2. Click **Create Credentials > API Key**
3. Đặt tên: `Vmito Mobile - Maps SDK`

### Cấu hình Key:

#### Application restrictions:
```
Chọn: iOS apps
- Bundle ID: com.vmito.app

Chọn: Android apps  
- Package name: com.vmito.app
- SHA-1 certificate fingerprint: [Lấy từ keystore của bạn]
```

**Cách lấy SHA-1:**
```bash
# Debug keystore
keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android

# Release keystore
keytool -list -v -keystore /path/to/your/release.keystore -alias your-alias
```

#### API restrictions:
```
✅ Maps SDK for Android
✅ Maps SDK for iOS
❌ Tắt tất cả APIs khác
```

### Sử dụng Key:

#### Cho iOS:
File: `ios/Flutter/GoogleMaps.xcconfig`
```
GOOGLE_MAPS_API_KEY = <your-maps-sdk-key>
```

#### Cho Android:
File: `android/local.properties`
```
MAPS_API_KEY=<your-maps-sdk-key>
```

## Bước 2: Tạo Key cho Places Autocomplete (Tìm địa chỉ)

### Trên Google Cloud Console:

1. Vào **APIs & Services > Credentials**
2. Click **Create Credentials > API Key**
3. Đặt tên: `Vmito Mobile - Places API`

### Cấu hình Key:

#### Application restrictions:
```
Chọn: iOS apps
- Bundle ID: com.vmito.app

Chọn: Android apps
- Package name: com.vmito.app
- SHA-1 certificate fingerprint: [Cùng SHA-1 như trên]
```

#### API restrictions:
```
✅ Places API (New)
❌ Tắt tất cả APIs khác (bao gồm cả Maps SDK)
```

**⚠️ QUAN TRỌNG**: Chỉ enable **Places API (New)** duy nhất. Không cần enable các APIs khác như:
- ❌ Maps SDK for Android
- ❌ Maps SDK for iOS  
- ❌ Geocoding API
- ❌ Directions API
- v.v.

### Sử dụng Key:

#### Cho tất cả environments:
File: `env/production.json`
```json
{
  "FLAVOR": "production",
  "API_BASE_URL": "https://vmito.com/api",
  "WEB_BASE_URL": "https://vmito.com",
  "GOOGLE_PLACES_API_KEY": "<your-places-api-key>"
}
```

File: `env/staging.json`
```json
{
  "FLAVOR": "staging",
  "API_BASE_URL": "https://staging.vmito.com/api",
  "WEB_BASE_URL": "https://staging.vmito.com",
  "GOOGLE_PLACES_API_KEY": "<your-places-api-key>"
}
```

File: `env/dev.json` (có thể để trống cho dev)
```json
{
  "FLAVOR": "dev",
  "API_BASE_URL": "https://staging.vmito.com/api",
  "WEB_BASE_URL": "https://staging.vmito.com",
  "GOOGLE_PLACES_API_KEY": ""
}
```

## Bước 3: Enable các APIs cần thiết

### Trong Google Cloud Console > APIs & Services > Library

Enable các APIs sau (chỉ một lần cho project):

✅ **Maps SDK for Android**
✅ **Maps SDK for iOS**
✅ **Places API (New)**

❌ **KHÔNG CẦN** enable các APIs khác trừ khi bạn sử dụng chúng

## Bước 4: Build và Test

### Build app với environment:
```bash
# iOS
flutter run --dart-define-from-file=env/production.json

# Android  
flutter run --dart-define-from-file=env/production.json
```

### Test các tính năng:

1. **Test hiển thị bản đồ**:
   - Vào trang "Tìm kèo"
   - Chuyển sang view "Bản đồ"
   - ✅ Phải thấy Google Map với markers

2. **Test autocomplete địa chỉ**:
   - Vào "Tạo kèo mới"
   - Nhấn vào "Chọn địa điểm" 
   - Gõ tên địa điểm (ít nhất 2 ký tự)
   - ✅ Phải thấy suggestions hiện ra

## Troubleshooting

### Autocomplete không hoạt động:

1. **Kiểm tra key có đúng không:**
   ```bash
   # Run app với logging
   flutter run --dart-define-from-file=env/production.json
   
   # Xem log khi gõ địa chỉ - sẽ thấy HTTP requests đến:
   # https://places.googleapis.com/v1/places:autocomplete
   ```

2. **Kiểm tra API restrictions:**
   - Vào Google Cloud Console
   - Chọn Places API key
   - Đảm bảo **chỉ có Places API (New)** được enable

3. **Kiểm tra Application restrictions:**
   - Phải có đúng Bundle ID: `com.vmito.app`
   - Phải có đúng Package name: `com.vmito.app`
   - SHA-1 phải match với keystore đang dùng

### Bản đồ không hiển thị:

1. **Kiểm tra file config:**
   ```bash
   # iOS
   cat ios/Flutter/GoogleMaps.xcconfig
   
   # Android
   cat android/local.properties | grep MAPS_API_KEY
   ```

2. **Kiểm tra API restrictions:**
   - Maps SDK key phải enable **Maps SDK for Android** và **Maps SDK for iOS**
   - KHÔNG enable Places API trên key này

3. **Build lại app:**
   ```bash
   flutter clean
   flutter pub get
   flutter run --dart-define-from-file=env/production.json
   ```

## Security Best Practices

1. **Không commit API keys vào git:**
   - ✅ `android/local.properties` - đã trong .gitignore
   - ✅ `ios/Flutter/GoogleMaps.xcconfig` - đã trong .gitignore
   - ⚠️ `env/*.json` - CÓ THỂ commit (vì có application restrictions)
   - ❌ `env/*.local.json` - KHÔNG commit (trong .gitignore)

2. **Sử dụng restrictions:**
   - Luôn set Application restrictions (Bundle ID, Package name, SHA-1)
   - Luôn set API restrictions (chỉ enable APIs cần dùng)

3. **Monitor usage:**
   - Vào Google Cloud Console > APIs & Services > Dashboard
   - Kiểm tra usage định kỳ
   - Set quota alerts nếu cần

### [ ] Step 7.2: Build app

**iOS:**

**Android:**
```bash

```

### [ ] Step 7.3: Test Google Maps

- [ ] Mở app
- [ ] Vào tab **"Tìm kèo"** (Home/Browse Sessions)
- [ ] Nhấn nút **"Bản đồ"** (Map toggle ở góc dưới bên phải)
- [ ] **✅ PASS:** Thấy Google Map với markers
- [ ] **❌ FAIL:** Map blank hoặc chỉ thấy grid

**If FAIL:**
- Check file: `ios/Flutter/GoogleMaps.xcconfig`
- Check file: `android/local.properties`
- Check Google Cloud: Maps SDK key có đúng restrictions?
- Rebuild app với `flutter clean`

### [ ] Step 7.4: Test Autocomplete

- [ ] Mở app
- [ ] Nhấn nút **"+"** hoặc vào **"Tạo kèo"**
- [ ] Scroll xuống phần **"Địa điểm"**
- [ ] Nhấn **"Chọn địa điểm"** hoặc trường address
- [ ] Gõ ít nhất 2 ký tự (ví dụ: "sân cầu")
- [ ] **✅ PASS:** Thấy danh sách suggestions xuất hiện
- [ ] **❌ FAIL:** Không thấy suggestions

**If FAIL:**
- Check file: `env/production.json`
- Check command: Có dùng `--dart-define-from-file=env/production.json`?
- Check logs: `flutter run --verbose`
- Check Google Cloud: Places API key có đúng restrictions?
- Test API key bằng curl (xem Phase 8)

## 📋 Phase 8: Advanced Testing (Optional)

### [ ] Step 8.1: Test Places API key với curl

```bash
curl -X POST \
  -H "Content-Type: application/json" \
  -H "X-Goog-Api-Key: [Your Places API Key]" \
  -H "X-Goog-FieldMask: suggestions.placePrediction" \
  -d '{
    "input": "sân cầu lông",
    "languageCode": "vi",
    "includedRegionCodes": ["vn"]
  }' \
  "https://places.googleapis.com/v1/places:autocomplete"
```

**Expected:** JSON response với suggestions array

### [ ] Step 8.2: Check logs

```bash
# iOS
# Open Xcode → Run app → Check Console logs

# Android
adb logcat | grep -i "google\|places\|maps"
```

Look for:

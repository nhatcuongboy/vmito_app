# Internationalization

Three locales, Vietnamese default — matching `NEXT_PUBLIC_DEFAULT_LOCALE=vi`.

## Locale codes differ from the web app

| Language | Web (next-intl) | Flutter |
|---|---|---|
| Vietnamese | `vi` | `vi` |
| English | `en` | `en` |
| Chinese | **`cn`** | **`zh`** |

`cn` is a country code, not a language code; Flutter and the platform
localization APIs use `zh`. `AppRoutes.stripLocale` still accepts `/cn` in
incoming web deep links.

## Pipeline

ARB files in `lib/l10n/`, compiled by `gen_l10n` (configured in `l10n.yaml`,
enabled by `generate: true` in `pubspec.yaml`).

```sh
flutter gen-l10n     # after editing any .arb
```

Generated output is git-ignored and excluded from analysis. Never edit
`app_localizations*.dart`.

```dart
final l10n = AppLocalizations.of(context);
Text(l10n.authSignIn);
Text(l10n.courtCallAnnouncement(courtNumber));
```

## Rules

1. **No hardcoded user-facing strings.** Same rule as the web app.
2. `app_vi.arb` is the template — add keys there first.
3. Missing translations land in `lib/l10n/untranslated.json`. That file is a
   worklist, and it must be empty before release.
4. Placeholders are typed. `int` for counts, `DateTime` for dates, `String`
   otherwise:

   ```json
   "courtCallAnnouncement": "Mời bạn vào sân số {courtNumber}",
   "@courtCallAnnouncement": {
     "placeholders": { "courtNumber": { "type": "int" } }
   }
   ```

5. Use `@key` descriptions for anything a translator could misread — especially
   badminton terms and anything spoken aloud by TTS.

## Naming

Flat, prefixed by area — ARB has no nesting:

```
common*    shared verbs and labels
error*     error messages, one per ApiErrorKind
auth*      sign in / sign up / reset
nav*       navigation labels
session*   session feature
court*     courts and the court call
tournament*
```

The web app's `pages` namespace alone is 2,811 keys — 47% of its 5,978. Do not
port it wholesale. Add keys as screens are built.

## Migrating from next-intl

Web messages live in `vmito-fe/src/i18n/messages/{vi,en,cn}.json`, nested. When
porting a screen, take only the keys that screen uses and flatten them:

```
pages.session.detail.title  →  sessionDetailTitle
```

Wholesale conversion would produce ~6,000 keys for the ~66 screens actually in
scope, most of them for admin and SEO pages that stay on web.

## Formatting

Use `intl` with an explicit locale, never a hardcoded pattern.

**Currency is integer VND with no minor units:**

```dart
NumberFormat.currency(locale: 'vi_VN', symbol: '₫', decimalDigits: 0)
```

`decimalDigits: 0` is not cosmetic — VND has no minor unit, and the backend
sends whole numbers.

## TTS

The court call is spoken aloud. `flutter_tts` must be given the **current
locale** and the localised string, not a hardcoded Vietnamese one. The web app
hardcodes `lang: 'vi-VN'`; do not copy that.

See [REALTIME.md](REALTIME.md#the-court-call).
